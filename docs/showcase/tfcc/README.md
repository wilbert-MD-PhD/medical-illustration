## 文件说明

- 两张无字底板按作者提供的 PNG 原样收录。
- PDF 来自作者提供的两页审阅稿。仓库版对文件结构和嵌入资源做压缩整理，图像保留原分辨率并使用无损压缩，保留文字与嵌入字体；原始文件保留在项目中。
- 两张 JPG 是 PDF 的网页预览，点击可放大；完整页面以 PDF 为准。
- 本组提供 PNG 与 PDF，不将其描述为已交付可编辑 SVG 或 Illustrator 源文件。
