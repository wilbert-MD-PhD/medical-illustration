## Skill 怎样自己找参考，再把参考用于绘图

这次用户提供了医学科普漫画的目标，没有提供下面三张图。Codex 按医学绘图 Skill 和项目规范，检索原始图页，从 **Frontiers 出版社**及 **NIH/NIAID BioArt** 下载参考到本地，查看原图、图注及许可，再把文件作为真实附件传给图像工具。已有合格参考则复用。

1. **先下载并看图。** 保存原始来源、作者、图号、下载地址与 SHA-256；打开本地图像核对内容。R05、R11 由下载的 WebP 转为输入用 PNG，图像内容保持不变。
2. **把参考变成具体绘图约束。** R05 用于第 3、5 格的表皮/真皮与伤缘覆盖关系；R11 用于表皮细胞形态及其与真皮的位置；R02 用于第 4 格巨噬细胞的胞体、突起和细胞核。指腹不照搬通用皮肤图中的毛囊，也不照搬深创口及全部细胞种类。
3. **实际附图生成。** 首次成功调用 G02 同时附入这三张图，以及 NIH 皮肤横截面和血小板/纤维蛋白显微图。记录保留实际附件顺序和原提示词，不把仅写在提示词中的链接算作参考输入。
4. **对照并返修。** 无字底图生成后检查结构和前后连续性，再独立排字；经过修订得到 v1.4。最近一次 G10 使用既有画面和 NIH 皮肤图返修，不宣称每一轮都重新下载、重新传入全部参考。
