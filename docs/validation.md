## 宿主验证的准确范围

本机项目要求使用既有串行适配器，因此实际派发通过该入口执行；测试加载了独立候选目录中的新版排字库。候选中的 `illustrator_session.jsx` 与实际使用的会话库字节相同，SHA-256 为 `de02ac517caf88f36cfe011f69205bb11e56d6b5d25beb85ee5bfe5c2c255ac6`。

随包 Python 适配器另做静态检查和模拟派发/锁回归；没有把“通过本机既有适配器”写成“在全新电脑逐步安装并执行了随包入口”。首次宿主运行已保存、关闭并检查成稿，但最后的测试记录使用了宿主不提供的 JSON 全局对象而报错；改用兼容记录器后，仅重开这份测试文件即完成核验。该记录器属于验收脚本，不是分发组件。

1.0.0 历史的两页宿主测试曾超时。本次排字库已接入显式会话，其成功验收属于1.1.0，不能倒填为旧版通过。测试为独立的非医学文字/图形页，不重建漫画主稿。
