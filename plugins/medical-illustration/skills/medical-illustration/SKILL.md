# 医学绘图

让读者通过画面看懂医学问题，并保留可追溯依据、可修改源文件和真实审核状态。先确认科研示意、解剖教学或科普叙事用途，沿用适用的项目视觉基准和当前主稿；用户要求优先于技能默认方式。

## 本 Skill 的更新与回退

用户要求“检查医学绘图 Skill 更新”“更新医学绘图 Skill”或“回退医学绘图 Skill”时，直接读取[更新操作](references/updating.md)，调用随包 `scripts/update_skill.py` 的对应命令；此类任务不启动绘图流程。只检查时不改文件；更新仅作用于实际加载的独立安装目录，保留已有授权，遇到未授权的本地修改替换才请用户选择。

## 功能选择与独立路径

按用户要交付的作品选择路径；两条功能各自执行，不串成一个流程。

| 用户任务 | 执行路径 |
|---|---|
| 生成/修改漫画脚本、分镜、对白，或制作/返修漫画 | 沿用下方漫画与医学插画决策、[原工作流程](references/workflow.md)、[文案与排字](references/copy-and-lettering.md)及[原模板](references/templates.md)，按当前阶段取用 |
| 涉及医学结构的科研示意图、机制图、图形摘要 | 从[科研绘图独立流程](references/research-workflow.md)进入；按需使用[科研图绘制规格](references/research-figure-spec.md)、[结构与机制规则](references/research-mechanisms.md)及[关系记录](references/mechanism-records.md) |
| 单幅解剖教学或其他医学插画 | 沿用原医学插画路径；明确用于科研图版时选择科研绘图分支 |

漫画中的科学机制讲解仍属于漫画任务，不因“机制”“细胞”等词切换流程。只要求漫画脚本时按原脚本范围交付，不强加科研图规格、关系 JSON 或生图。科研图不自动载入漫画脚本、角色、对白、气泡、分镜、整书风格或漫画初始化器。用户同时需要两类作品时分别维护各自的脚本/图稿，按来源 ID 复用适用证据，不改写另一类作品。

以下两节与原初始化器用于原漫画/医学插画功能；科研任务直接走独立流程。两条功能共同遵守后文医学真实性、参考用途、真实审核状态与软件收尾边界。分支选择不覆盖用户及项目中实际适用的明确要求。

## 漫画与医学插画：核心决策

- 允许真实参考约束下直接生成**整页、连续场景或单幅彩色无字画面**。线稿、三维底图、透明角色素材与分层合成按结构复杂度、修改和复用需要选择，不设固定优先顺序。
- 全书固定角色识别、主要视觉语言和医学术语；镜头、动作、场景、分镜数量及构图服务内容。已有姿势或素材不适合新页时制作新版本，不勉强拼贴。
- 医学结构、侧别、动作、病灶与医学论断由真实证据约束。实际打开匹配本地参考并核验用途；使用参考图生成时真实附入工具，生成后实际看图对照。已有合格参考可复用，新结构/视角/病变/用途或不足时再补查。
- 对每项承担医学讲解的解剖结构，建立“成图位置—具体结构关系—可信来源及图号/页码—实际使用方式—对照结果”的对应记录，可合并在已有脚本或来源表中。区分文献/图谱依据、模型投影、生成附件、配色参考与展示裁图；复用底图继承原来源链和待审状态。需要实例时看[人类医生腕骨漫画的参考对应示例](references/anatomy-evidence-example.md)。
- 生成前规划本页标题、对白与标签空间，底图不预画气泡或文字框；生成后先试排。保留原始无字位图；正文、医学标签及后加箭头独立可编辑。只在实际需要时分出人物、背景或结构，不虚构整页位图的内部图层。
- 虚构人物反应、对白、幽默和生活情境可用于叙事；不能编造医学因果、疗效、真实病例或第一人称真实经历。修改医学表达后核对适用条件、数值、概率与图文含义。
- 返修保护非目标已认可区域。脸部、医学结构、器械本身是修订目标时可按匹配参考修改；局部缺陷优先局部修，整体叙事/风格/构图问题可重做相关整页并复核。

## 控制随医学风险变化

精细解剖、术式、查体、影像、固定和康复教学重点核对空间与操作，建议相应临床/解剖专家审阅。机制图分别核对结构拓扑、跨区室定位、连线语义与证据强度；定位和医学用途运动图核对实际所表达的关系。普通对白、表情与非教学性生活场景只需相关人物/肢体/连续性检查，不因出现人就套完整高风险表。项目使用 H/M/L 时可沿用，字段不清不妨碍先写探索性脚本。

解剖图、机制示意、功能比喻与诊断影像须明确区分。科研示意图区分已支持关系与探索性假说，不把未证实机制画成确定因果；本技能不代替实验数据分析或统计作图。功能模型不替代真实形态；模型生成影像不得充当诊断证据。来源不明、搜索缩略图或 AI 自绘解剖不能证明结构正确。

## 真实进度与边界

人工审阅为建议环节，用户或项目明确要求先审后做时遵从。仅缺人工签字可继续已授权制作并交付“制作完成，医学待审”的制作稿；不得代填审核人或宣称医学通过、印前批准。AI 对照、视觉检查、文件检查和人工签字分别报告。

关键证据不足、侧别/结构冲突未解、必要用途许可缺失或已发现医学错误，只暂停受影响步骤并继续独立工作。缺独立线稿、未填无关模板字段、未跑固定轮次不构成阻断理由。只核查摘要时明确范围，不对其未支持的细节做结论。

来源登记和版权、患者/肖像授权按实际用途核验；可阅读或已下载不等于可输入 AI、改编或商业出版。出版规格未定可用明确的工作规格制作，不宣称已符合出版社印前要求。

Illustrator 完成后保存并关闭本任务登记的标签页，保持程序运行；已有文档不接管。调用按运行说明串行执行，异常恢复保存失败才保留并报告。
