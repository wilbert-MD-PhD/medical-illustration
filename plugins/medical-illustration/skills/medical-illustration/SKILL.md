# 医学绘图

制作可追溯、可审签、可修改、可交付的医学科普插画与漫画。视觉完成度不能替代医学正确性；本 skill 不能代替临床、解剖或印前人员签字。

**流程可迁移，但医学审核责任不可迁移。** 复制、安装或修改本 skill，不代表获得原作者、原项目或原审稿人的医学批准。每个新项目必须按风险与交付用途，由实际承担责任的人员完成适用的临床、解剖、编辑和印前审核与签署。

安装、迁移或验收本 skill 时，读取 [依赖、安装与验收](references/dependencies-installation.md)。不含私有角色、解剖母版或病例素材的最小示例见 [通用示例项目](examples/generic-visit-preparation/示例说明.md)。

## 先选择工作模式

- **完整项目**：从选题、证据到印前交付。读取 [workflow.md](references/workflow.md)、[copy-and-lettering.md](references/copy-and-lettering.md)、[templates.md](references/templates.md)、[generation-and-assets.md](references/generation-and-assets.md)、[revision-and-prompting.md](references/revision-and-prompting.md) 和 [qa-and-prepress.md](references/qa-and-prepress.md)。
- **单幅或单页制作**：仍须完成风险分级、证据绑定、空间规格和相应审核。含文字时同时读取 `copy-and-lettering.md`。
- **审稿或返修**：不重做无关区域。读取 `revision-and-prompting.md` 和 `qa-and-prepress.md`，先建立编辑合同和变更集，再修改并检查保护区。
- **印前交付**：以出版社书面规格为准。读取 `qa-and-prepress.md`。

先记录当前请求的范围、阶段和载体，只执行适用门禁。不适用项记录理由，不虚构证据、母版或签字：L 级生活场景可无医学论断与解剖母版；单幅无连续角色时不要求角色系统；纯文字返修不重走图像生成。草稿可使用注明待确认的尺寸；出版社规格只阻断印前锁定和印刷交付，不阻断合规草稿。数字交付读取 [数字交付检查](references/qa-and-prepress.md)，完成医学和编辑审核后另记发布决定。

用户未指定目录结构时，可运行：

```bash
python3 scripts/init_medical_project.py <项目目录>
```

从 `SKILL.md` 所在目录解析脚本路径；Windows 可用 `py -3` 替代 `python3`。脚本只补充缺失目录和模板，不覆盖现有文件。

## 八条不可妥协的边界

1. 将**医学事实层**与**美术表现层**分离。解剖、侧别、附着、病灶、动作、器械、影像和诊疗路径属于医学事实层，不允许生成模型自由决定。
2. 关键医学结构必须来自经核验的母版、合法真实影像或人工医学线稿。提示词不能证明解剖正确。
3. 已经医学通过的结构不得因修改人物、背景、配色或构图而重新生成、镜像或变形。
4. 连续角色依赖角色圣经、转面图和锁定资产，不依赖模型记忆。
5. 所有可被读者当作医学事实的陈述必须绑定可核验的证据编号；不能核验则降级表述、标记“待核”或删除。
6. AI、自检脚本和视觉 QA 均不能签署人工审核。未完成所需医学审核时，产物保留 `草稿` 或 `医学待审`，不得称为医学通过或出版级终稿；已完成的审核按变更影响保留记录。
7. 每张图生成前必须先完成结构化、模型中立的详细 prompt 和渲染清单。Prompt 锁定意图，不代替参考图、母版、蒙版或图层锁定，也不承诺不同模型像素级一致。
8. 凡涉及解剖结构，绘制前必须从可核验的权威网络来源取得可参考图像，下载至项目本地并完成来源、许可证和解剖约束登记；未完成不得开始解剖绘制。

## 图像分类与风险

先明确每幅图的用途，禁止混用：

- **解剖图**：真实结构和空间关系；必须审核结构、侧别、视角、比例和附着。
- **机制示意图**：受力或运动；明确前后状态、箭头含义，并标注“示意图”。
- **功能模型**：吊床、绳索、齿轮等比喻；标注“功能模型，非真实解剖形态”。
- **拟人漫画**：辅助记忆或表达感受；不能承担精确定位、诊断或疗效结论。
- **医学影像**：诊断性用途只使用获授权、去标识化的真实影像；AI 生成画面只能标注为非诊断示意，不得伪装成 X 线、CT、MRI 或超声。

风险等级决定最低控制：

| 等级 | 范围 | 最低要求 |
|---|---|---|
| H | 解剖、手术、查体、医学影像、固定、康复动作 | 锁定母版或人工医学线稿；临床与解剖双审 |
| M | 损伤机制、疼痛定位、运动姿势、医疗器械 | 解剖空间规格卡；至少一名相关临床审稿人 |
| L | 对话、表情、生活场景、装饰 | 可生成；检查肢体、角色和跨页连续性 |

任何涉及高风险操作或争议性结论的内容，审核人必须来自相应亚专科。

## 工作次序与门禁

按 G1–G11 推进；前一门禁未通过时，不把后续产物称为已批准：

1. `G1` 页面目标与 H/M/L 风险分级完成。
2. `G2` 证据矩阵、术语和表述强度锁定。
3. `G3` 连续角色母版与必要肖像授权锁定。
4. `G4` H/M 图的本地解剖参考包、医学母版与解剖空间规格卡批准。
5. `G5` 逐页脚本绑定证据、角色和医学母版编号。
6. `G6` 文案完成受控 humanize，并通过逐句医学语义回归；未通过不得进入分镜。
7. `G7` 分镜的阅读顺序、图文关系、侧别和箭头批准。
8. `G8` 先审纯医学线稿；H 级临床与解剖双签后才上色。
9. `G9` 分层合成并在 Adobe Illustrator 或等价可编辑矢量工具中确定性排字；返修必须通过适用的局部修改完整性和气泡排字门禁，再进行人物、医学和文字回归检查。
10. `G10` 全册 A/B 级问题清零，所有 H 级页面双签。
11. `G11` 交付检查完成：印刷作品完成医学终审、文字终校和印前预检；数字作品完成适用医学与编辑审核、数字输出检查和项目负责人发布决定。

## 证据和术语

- 优先使用专业学会指南/共识、权威图谱和教材、系统综述，再到原始研究与高质量叙述性综述。
- 在输出引用前核验题名、作者、期刊、年份和 DOI/PMID/URL；关键结论尽量核查全文及具体页、图或段落。
- 搜索摘要、商业网页、患者文章和其他漫画只能提供线索，不能单独证明解剖或诊疗结论。
- 证据矩阵记录“支持范围”和“绘图影响”，禁止把“可能”画成“必然”。
- 全项目使用一份术语表，包含标准中英文名、公众表达、禁用表达和首次解释。

## 生成与绘制工具路由

- 知识漫画可用 `baoyu-comic` 生成内容分析、角色规划、分镜和逐页提示词；其产物仍须进入本 skill 的 G1–G11 门禁。
- 栅格概念图、低风险人物和场景可用 `imagegen`。每张图在生成前保存基础规格、医学空间规格、锁定项、禁止项和本次变更集；使用参考图锁定角色，先生成无字底图。
- 数据型患者教育图可用信息图工具生成草图；数值、图表和来源必须人工复核，最终优先保留可编辑矢量或分层源文件。
- 凡含解剖结构，先建立本地参考包，再使用人工矢量绘制、经审核的公开矢量、3D 医学模型或合法真实影像制作医学事实层。生成工具只可辅助非事实表现层或受控上色。
- 不通过对错误位图覆盖文字或局部涂抹来伪装修正。医学结构错误必须回到母版或线稿重做并重新审核。
- 修改时不用重写后的完整 prompt 盲目重生整图。保留基础 prompt，只新建变更集；已批准的医学层必须复用原资产。详见 `revision-and-prompting.md`。

## 文案与文字添加

- 对白、标题、旁白和面向公众的解释，在医学事实稿锁定后做受控润色；可用 `$humanize-writing`，不可用时按 `copy-and-lettering.md` 手工改写并执行相同语义回归，不因缺少该可选 Skill 停止文案工作。
- 解剖名称、数值、方向、侧别、剂量、时序、适应证、禁忌证和免责声明不做自由 humanize，只按术语表和文字校对规则处理。
- 最终文字使用 **Adobe Illustrator** 或等价可编辑矢量排版添加。保留无字底图，医学事实层、箭头标签层、正文层和对白层分离；不让图像生成模型承担最终文字渲染。对白气泡必须进行安全内框、最小字号、均衡换行、溢出和实际成书尺寸检查。

## 产物与状态

每个页面保留页面任务、风险等级、审核记录和版本变化，并按任务保留证据编号、解剖参考图编号、角色资产编号、医学母版编号、空间规格、结构化 prompt、渲染清单、变更集与线稿；不适用项注明理由。

状态只使用：`草稿`、`医学待审`、`退回修改`、`医学通过`、`编辑通过`、`印前锁定`。避免“最终版”“最终最终版”等名称。

制作阶段另记，如分镜、待排字、审校样、数字交付；不把它们当作审核状态。逐项保存临床、解剖、编辑与印前审核的范围、版本、结论、人员和日期。医学已通过但印前未完成时保留有效医学批准；数字作品通常以 `编辑通过` 加数字交付检查和发布决定交付，不伪记 `印前锁定`。无医学事实的 L 级作品将医学审核记为不适用，不虚构医学批准。返修对既有批准的影响按 `qa-and-prepress.md` 的变更表判断。

文件名使用 `[项目]-[页码]-[内容]-[阶段]-V[主版本].[次版本]-[状态].[扩展名]`，例如 `通用示例-P01-就诊信息整理-分镜-V1.0-草稿.svg`。

修改任何医学结构、侧别、动作、器械、影像、诊疗文字或含医学内容的生成区域，原 `医学通过` 状态立即失效；重新检查修改对象、邻近结构、方向、标签、正文、人物和跨页连续性。

## 停止条件

以下缺口只阻断对应操作；说明缺口并继续已授权且不依赖它的工作：

- 侧别、视角、体位或箭头含义无法确定；
- 关键结论无可靠证据或仅有摘要；
- H/M 图没有空间规格卡或医学母版；
- 解剖内容没有已下载的可核验本地参考图和来源登记；
- 生成前没有结构化 prompt 和渲染清单，或返修时无法确定修改区与保护区；
- 真实影像来源、授权或去标识化状态不清楚；
- H 级医学线稿未获得当前版本的临床与解剖双签时，不进入该医学层上色或发布；允许依据已核验参考制作供人工审核的线稿，不得代签；
- 出版社尺寸、出血、色彩、字体或 PDF 规格未书面确认时，不进入印前锁定或印刷交付；草稿注明暂定规格，数字作品执行数字交付检查。
