# 首次环境检查与开始制作

目标是验证当前使用者的环境能否完成具体任务。安装完成与制作就绪分别报告，按宿主实际工具和权限选择路径。首次跨 Agent 接入见[能力映射](agent-integration.md)。

## 1. 验证 Skill 安装

读取实际安装位置的 VERSION、SKILL.md 和 SHA256SUMS，检查清单中所有文件的 SHA-256 与相对资源。确认没有同名旧版本干扰加载。安装前先检查目标目录。更新时记录实际路径，保留使用者的改动，再根据已授权范围更新。

按宿主方式刷新并调用 `medical-illustration`，支持 `$medical-illustration` 时可用该语法。没有技能发现机制时，直接读取入口及本次引用资源。分别记录文件校验与实际加载结果。

## 2. 按能力检查与补齐

| 能力 | 首选 | 缺失时的处理 |
|---|---|---|
| 项目初始化 | 当前 Python 3.9+，只用标准库 | 先复用宿主或项目已有运行时。仍无 Python，可手工建立模板，或按平台官方安装方式补齐 |
| 图片生成 | 当前会话实际可调用的图像工具 | 检查工具清单及对应使用说明，确认图像接口确实可调用。需要用户登录、启用服务或配置本地环境变量时明确说明 |
| 中文字体 | 已安装且覆盖所需汉字的字体 | 核验真实字体文件及许可；可从思源黑体、Noto CJK 或霞鹜文楷的官方项目获取并按平台安装，保留许可；不依赖作者电脑字体名称自动存在 |
| 可编辑排字 | 按目标格式选 [PPTX 原生对象](pptx-delivery.md)、Illustrator（macOS 可用随包[运行器](illustrator-runtime.md)）或 SVG/矢量工具 | 缺少指定格式能力时列明待制作部分，现有可编辑格式保留，不以整页图片替代 |
| PDF 导出和页面检查 | 按源格式选 Office、矢量工具或浏览器导出，再渲染页面 | PPTX 按专用路径验收同源导出，SVG/文字排版可按下方 Python 路径补齐。实际导出并查看页面 |
| 医学依据和审稿 | 用户资料、可核验来源、项目实际审核人 | 资料不足先做可核验范围的分镜或非医学表现层；按内容风险分别记录制作和人工待审状态 |

不要批量安装所有相关 Skill、3D 软件或商业软件。`humanize-writing` 与 `baoyu-comic` 缺失时使用包内流程。只有当前任务确有缺口，才从官方来源补齐所需组件。

### 免费 Python 导出路径（SVG/文字排版需要时）

PPTX 的 PDF/PNG 使用其已保存源稿导出，本节用于独立的 SVG/文字排版路径。优先复用当前运行时已有组件。需要新依赖时，在漫画项目内创建专用虚拟环境，用该环境的 Python 安装 `reportlab` 和 `Pillow`；它们用于文字/PDF 和图像读取，不提供图像生成服务。安装前核对官方文档与当前 Python 兼容性，记录实际安装版本；不要修改系统 Python 或无关项目环境。

macOS/Linux 的环境 Python 通常在 `.venv/bin/python`，Windows 在 `.venv\Scripts\python.exe`。以实际创建路径为准。若 PDF 渲染工具缺失，可使用已具备的浏览器、系统预览或按对应官方说明安装 Poppler。使用中文字体时选所用导出器实际支持的字体文件；仅看到一个字体家族名称不算验收通过。

## 3. 最小实际验收

按本次任务选择以下验收。仅写脚本时验收读写与来源能力，独立科研图按其专用流程检查。缺少的执行或看图能力按[适配说明](agent-integration.md)记录交接。

1. 需要漫画/医学插画初始化器时，在临时目录运行两次，确认现有文件未被覆盖。
2. 按本次源稿格式制作一张含“医学科普漫画：中文排字测试”的独立文字层。选择 PPTX 时加入原生箭头/引线，并按[专用路径](pptx-delivery.md)导出 PDF、PNG。SVG/AI 任务使用其实际源格式。
3. 重开源稿并查看导出，检查汉字、换行、边界与对象可编辑性，保留使用字体和导出器记录。本次任务已有合格产物时可直接作为验收对象。
4. 本次需要生成或编辑图片时，检查当前图像工具。优先使用本次会话已有成功调用作为证据；否则，在符合使用者授权和费用范围时生成一张无医学内容的小型测试图。未实际调用成功只能记为“工具已发现，生成未实测”。
5. 逐项报告通过、未实测或缺失，以及具体文件路径；依赖安装不能代替上述结果。

验收图像不包含解剖、查体、康复动作或临床建议，不冒充医学作品审签。

## 4. 收集需求后制作

沿用用户已给出的主题、读者和范围，按[任务入口](../SKILL.md#选择任务路径)进入相应分支，采用该图型的格式与检查。医学依据和审核状态按入口共用规则，出版规格未定时按质量规则制作工作稿。
