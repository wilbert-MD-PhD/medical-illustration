# 科研图绘制规格：专用模板

仅用于[科研绘图工作流程](research-workflow.md)。漫画继续使用原页面脚本和模板。本模板按实际任务取用，可并入现有图稿说明；纯结构图省略机制关系，局部返修只补受影响信息，不重复维护 Markdown 与 JSON。

## 图稿目标

- 图稿 ID/版本、当前主稿和输出位置：
- 图型、读者、用途；已知目标期刊/图型政策及核查日期：
- 一句话主旨；本图要回答的问题：
- 物种/组织/细胞/实验模型与必要时程条件：
- 用户实测结果、文献背景和假说的范围；证据记录链接：
- 可见图题、标签、必要缩写与图注草稿：
- 工作尺寸/语言；待确定规格；本次交付与可编辑范围：

## 结构与视觉参考

| 对象 ID | 结构/状态及区室 | 视角/切面与连接/层次约束 | 允许简化与关键避错点 | 参考 ID、实际查看位置 | 对应图上对象/区域 |
|---|---|---|---|---|---|

参考 ID 链接已有来源主记录：本地文件、来源/图号、支持范围、具体用途与实际查看记录。用于 AI 输入的附件另关联真实调用记录；风格参考和医学参考分别说明用途。只画抽象分子符号时不虚构精确三维形态依据。

## 机制关系（有此内容时填写）

沿用[关系记录](mechanism-records.md)的表或 JSON，不重写其 schema。按实际需要在表中补充运输途径、证据类型/条件和图上对象映射；现有检查器不自动检查这些补充信息。

| 关系 ID | 起点与终点/区室；必要运输路径 | 关系与直接性 | 证据来源类型、支持范围与条件 | 来源/核验位置 | 线型、端点及图上对象 ID |
|---|---|---|---|---|---|

区分用户观察、相关分析、干预证据、文献背景和提出的假说；不凭填写了来源 ID 就判定因果或直接结合。缩写、颜色、端点和线型在本图采用一套明确图例。

## 构图与绘制输入

- 主视觉、阅读顺序、分区/比较/时间过程与放大选区：
- 视觉表现：平面/2.5D/三维，重点与背景的细节层级、材质、透明度、轮廓及光影：
- 最终标签容量、位置、引线路径与须避让结构：
- 实现方式与对象编辑范围；实际附入的医学参考/风格参考/草图：
- 本次真实提示词或绘制程序、工具及可得模型信息、原始输出与采用版本：
- 返修目标、保护区域及依赖此处的相邻结构/标注：

首次生成前将适用约束写入实际输入，不只留在本模板。未调用工具时如实记未调用；未要求过程演示时无需补造草稿。

## 图注与检查记录

图注按实际内容说明核心结论、模型、符号/缩写、被省略的关键中间步骤和必要来源；工作状态与管理编号留在制作记录。按图稿用途决定哪些内容可见，不套用漫画对白或逐页旁白规则。

| 检查层 | 检查对象/版本与依据 | 实际结论/未检查项 | 修订及复核位置 |
|---|---|---|---|
| 医学结构对照 | | | |
| 机制关系（如有） | | | |
| 视觉表现与实际尺寸可读性 | | | |
| 源文件可编辑性与导出 | | | |

另记人工审签凭据（如有）、投稿/印前核查范围与当前状态。未执行不得填通过，人工未签保持医学待审。科学与视觉缺陷逐项定位，不用整体评分代替检查。
