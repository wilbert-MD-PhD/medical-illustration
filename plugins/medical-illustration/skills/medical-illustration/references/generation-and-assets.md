# 生成与资产制作

## 选择方式

按画面目标、结构复杂度和复用需要选择。线稿、三维底图与分层合成按实际需要使用。

| 需要 | 合适方式 |
|---|---|
| 科研区室、通路、结构与分子机制 | [科研绘图流程](research-workflow.md)中的全矢量或结构底图配可编辑关系与标签 |
| 人物互动、生活场景、连贯叙事 | 整页或连续场景直接生成彩色无字画面 |
| 清楚展示的医学对照/局部 | 匹配真实参考约束下的单幅或整页，成图逐结构核对 |
| 精细附着、多层遮挡、术式、反复失败的动作 | 先做可核对的线稿、矢量或三维约束，再完成表现 |
| 经常换位置或重复使用的角色/器械/结构 | 独立高分辨率素材，保留版本与来源 |
| 诊断性影像 | 有授权、去标识化且方向核对的真实影像 |

旧素材适合才复用，新镜头可制作新姿势。全书固定角色身份、主要视觉语言和医学术语，镜头、动作、场景与构图服务内容。整页位图保留原件，拆层按修改需要进行，如实说明内部不可编辑的区域。

## 实际提示词与输入

先写故事与视觉重点，再写构图、角色/风格、医学约束和返修保护范围。只加入本页适用要求。医学参考的取得、实际查看、附件和用途统一按[参考规则](anatomy-reference-search.md)执行。角色和风格图也须实际查看并按工具要求附入，分别说明用途。

保存真实提示词、工具及可得模型信息、实际输入附件、原始输出和修订映射，字段见[生成记录](templates.md#生成调用记录)。保留原始无字底图，最终文字确定性排版。角色固有 logo/字样按项目设定保留。

漫画生图前的留白和生成后试排统一按[文字空间](text-space-and-visible-copy.md)执行。科研图的标签和连线路径按其图稿规格安排。

## 画面检查与修正

实际查看输出，检查肢体连续性、物体接触和参考约束。医学结构按参考逐项对照，不能以粗糙通用图形冒充已核验终稿。返修目标、保护区域和复核范围按[质量规则](qa-and-prepress.md#缺陷与返修)执行。

仅实际抠图资产在深浅背景检查白边/晕圈。记录原始像素和最终置入尺寸，计算有效 PPI，上采样不等于增加细节。多页比较人物身份、衣着、尺度、动作与场景光色。

真实影像检查像素内文字、DICOM 信息、日期/机构、方向和可识别重建，去除姓名不足以完成去标识化。来源及各用途许可登记在既有来源主记录，具体要求见参考规则。
