# PPTX 制作与同版交付

用户指定 PowerPoint/PPTX 时使用本路径。未指定源格式且需要直接修改图中文字、箭头和引线时，也可选择此路径。可选交付组合为 PPTX 源稿、PDF 审阅稿及逐页 PNG。沿用用户指定格式、画布和当前主稿，只要求脚本/方案时不扩展成文件制作。

医学依据按[参考规则](anatomy-reference-search.md)，画面制作按所属漫画或科研分支。PPTX 是可编辑图稿载体，不改变作品的图型、视觉风格或科学内容。

## 选择工具与规格

- 按宿主已验证能力选择 PowerPoint、支持原生对象的演示文稿 API/库或其他 PPTX 编辑器。相关技能可用时按其说明调用，无须先经 Illustrator 或 SVG 转换。指定 AI 的任务仍走原生 AI 路径。
- 排版前确定最终物理尺寸、页面方向、语言和可编辑范围。一幅图通常占一页，不强制 16:9。需要多图版时沿用原图编号与阅读关系。
- 确认可用中文字体、实际导出器及页面渲染能力。没有 PPTX 写入能力时交付已完成素材与对象定位说明，标记源稿待制作。只能生成 PPTX 时保留源稿，并列明 PDF/PNG 待导出。

## 建立原生对象

| 内容 | 实现与核对 |
|---|---|
| 标题、正文、医学标签、图例 | 原生文本框，保留 Unicode 文字和可改字的文本运行。对中文与西文设置所需字体，检查东亚字体设置及实际缺字情况 |
| 标签引线、机制箭头、抑制端点 | 原生连接线或路径。方向、实虚线、箭头端与 T 端显式设置，T 端可由独立短线与主线成组构成 |
| 气泡及其他文字容器 | 原生形状，与文字分开控制填充透明度。漫画空间与样式按[文字空间](text-space-and-visible-copy.md) |
| 医学底图或复杂结构插画 | 嵌入已核验的无字原图，等比放置。记录原始像素、置入尺寸和不可单独编辑的区域 |
| 需要单独修改的结构 | 原生形状、路径或已验收的独立对象。导入 SVG 后仍作为单张图片时，不能算结构可逐项编辑 |

给关键对象稳定名称，如 `label-01`、`edge-01`、`base-01`，与现有图稿/关系记录关联。按修改需要分组，保留文字、引线和底图各自的选择能力。移动对象后核对连线落点，既可采用实际连接到对象的连接线，也可显式重定位端点。

按最终尺寸试排真实文字，显式设置字号、行距和文本框内边距。避免自动缩字掩盖空间不足。多段混排逐段检查换行、上/下标和符号，图题与图注按原作品用途放置。

## 从同一份源稿导出

1. 保存并重新读取最终 PPTX，检查页面尺寸、对象名称、实际文字及外链。将其路径、版本和 SHA-256 记为本批次源稿。
2. 使用当前环境获准的 Office 导出器从这份已保存 PPTX 生成 PDF，再由该 PDF 渲染逐页 PNG。宿主已有统一渲染入口时优先使用。其他导出路径须另核文字、页序及图形一致性。
3. 记录导出器及版本、源稿哈希、PDF/PNG 路径与哈希、页序对应、PDF 页框尺寸和 PNG 像素尺寸。PPTX 修改后重新导出受影响的交付批次，旧版成套保留。
4. PNG 分辨率按用途选择，像素尺寸由物理尺寸和目标 DPI 计算。例如宽度像素约为“宽度毫米 ÷ 25.4 × DPI”。上采样不增加底图细节，屏幕预览和印刷图分别按实际规格验收。

源稿、PDF 与 PNG 使用同一图稿 ID/版本，逐页编号一致。记录可并入已有交付表，无须新增独立台账。导出器不支持某种对象时修正源稿或改用可靠导出器，并复核新输出。

## 验收

| 检查 | 完成条件 |
|---|---|
| 原生可编辑性 | 在可用编辑器或读写库中重开，核实标签为文本对象、箭头/引线为独立路径对象。用临时副本改一处中文标签并移动一条引线，保存重开后确认修改保留，正式源稿保持原样 |
| 三种格式一致 | 对照最终源稿核查 PDF 的文字、页序、尺寸和对象位置，再查看由其渲染的每张 PNG。哈希证明文件身份，不能单独证明视觉一致 |
| 实际画面 | 按[质量检查](qa-and-prepress.md)看最终使用尺寸及必要局部放大，重点检查中文行距、标签与结构间距、端点、细线、透明度和对象遮挡 |
| 编辑范围 | 如实列出可编辑文字/线条/结构及栅格底图范围。整页截图、文字转曲或只有一张 SVG 图片不能替代约定的原生对象 |

重开和修改测试记录实际所用程序。经库读取或 LibreOffice 渲染不等于已在 PowerPoint 中验收，未经实测的应用兼容性保持未测。保存实际输出后按[文件管理](file-management.md)交付，审核状态按[共用规则](../SKILL.md#共用医学与进度规则)记录。
