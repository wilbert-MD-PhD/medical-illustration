# Agent 适配与能力映射

## 加载同一份 Skill

本包采用 [Agent Skills 格式](https://agentskills.io/specification)：`SKILL.md` 提供名称、说明和入口，`references/` 按任务读取，`scripts/` 提供可选执行辅助。宿主可以通过本地文件、资源接口或上下文注入提供这些内容，参见[接入说明](https://agentskills.io/client-implementation/adding-skills-support)。

| 当前 Agent 的能力 | 接入方式 |
|---|---|
| 原生识别 Skill | 将完整 `medical-illustration/` 放到该宿主实际配置的技能目录，刷新后核对加载路径与 VERSION |
| 可读文件，但没有原生 Skill | 将完整目录放到可访问工作区，在任务中指定 `SKILL.md` 的实际路径，沿相对链接按需读取 |
| 仅支持附件、知识库或资源接口 | 保留完整包，以附件或资源接口提供入口及本次所需引用文件，记录原相对路径。资源缺失时请求补齐受影响部分 |
| 仅文本对话 | 提供入口和相关分支正文，可完成文案、分镜、规格与检查计划。图像、文件执行和视觉验收交接给具备能力的工具或人员 |

完整包是维护和更新单位，单次上下文按需载入。完整目录中的 `agents/openai.yaml` 是可选 OpenAI 界面适配，其他宿主可忽略它。仓库外层 `.codex-plugin/` 与 Marketplace 元数据服务相应插件宿主，独立 Skill 使用不依赖这些目录。保留已分发文件及其校验清单，忽略适配文件无需删除文件。

## 可直接使用的请求

```text
请读取已提供的 medical-illustration/SKILL.md，并按任务读取相关参考文件。
为没有医学背景的读者制作一页伤口愈合科普漫画。
先确认当前可用工具，再完成可信参考、分镜、彩色无字画面、可编辑排字和 PDF。
实际缺少的能力请列出具体待办，并继续完成可以独立交付的部分。
```

将示例入口替换成实际路径或资源标识。支持技能名称调用时可直接说“使用 medical-illustration”。`$`、斜杠命令、安装器名称和插件命令由宿主决定。调用其他技能前确认它确实可用，包内流程可独立使用。

## 将任务映射到能力

| 所需能力 | 可接受的实现 | 能力不足时 |
|---|---|---|
| 读写项目、记录来源和版本 | 文件工具、资源存储、文档 API，或用户保存交付文本 | 交付明确命名的文本与保存位置建议，不声称已落盘 |
| 核验医学来源 | 用户提供的可核验资料、检索/浏览工具或学术接口 | 基于现有可核验证据推进，缺证据的医学细节留待核实 |
| 查看参考和成图 | 多模态看图、PDF 页面渲染或实际人工视觉检查 | 可以核对文件和文字，视觉状态记录为待检查 |
| 生成或编辑图片 | 支持本次输入、尺寸和编辑需求的图像工具/API | 可用矢量绘制或已有合规素材完成适合的图形，需生成的部分交付提示词与输入清单 |
| 参考图约束 | 工具真实收到参考图附件并返回结果 | 改用支持附件的工具或可核验的矢量/三维路径，不把提示词中的文件名记作已附图 |
| 可编辑排字与绘图 | 原生文字/路径对象、SVG 或适用的矢量编辑器 | 提供真实可编辑格式。用户指定 AI/PPTX 时单列原生格式转换与验收 |
| PDF/预览与视觉检查 | 可用导出器、页面渲染器和图像查看能力 | 保存源文件和具体导出/检查待办，完成后再更新状态 |
| 运行辅助脚本 | Python 3.9+，可选裁切依赖 Pillow | 用相同模板人工组织，或交接命令。写出命令与实际执行分别记录 |

图像工具、浏览器、Shell、MCP、SDK 和桌面自动化都按实际可用接口调用。先读其使用说明，按实际输入格式传图和文件。用户资料的上传、依赖安装和软件控制遵循宿主权限与现有授权。

## 平台、状态与交接

Python 初始化、关系检查和更新工具可在支持的 Python 环境执行。随包 Illustrator 自动派发依赖 macOS、Illustrator 和自动化权限，其他环境采用 SVG/矢量流程或已验证的适配器，详见[Illustrator 运行说明](illustrator-runtime.md)。执行同一 Illustrator 实例的所有入口应共用锁，保留已有文档和本任务的显式登记。

分别记录：资源已加载、工具已发现、实际调用成功、文件已生成、逐页视觉检查、人工医学审阅与印前批准。交接材料保留当前源文件、参考及用途、实际执行记录、未完成步骤和检查状态。恢复任务时先读当前记录，沿用用户已给出的范围和授权。
