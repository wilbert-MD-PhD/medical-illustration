# Prompt 规格、版本继承与局部返修

## 基本判断

Prompt 是可追踪的画面规格，不是可编辑源文件，也不能单独保证解剖正确性。不同模型只要达到相同的语义、空间关系和视觉目标即可；不承诺像素、轮廓或构图完全一致。已批准区域的继承依靠原始资产、参考图、蒙版和锁定图层，不依靠模型记忆或 prompt 复现。

## 每张图的生成前输入

先保存一份模型中立的标准 prompt，至少包含：

1. 页面目标、用途、画布尺寸和预期阅读尺寸；
2. 场景、人物、动作、镜头、构图、光线、色彩和媒介；
3. 医学空间规格：侧别、视角、体位、方向、层次、附着、必须结构和禁止结构；
4. 角色、医学母版和本地解剖参考图的编号及用途；
5. 锁定项、允许变化项、禁止项和无文底图要求；
6. 医学事实层与非事实表现层的边界。

不把模型专有语法写入标准 prompt。如需特定模型参数，从标准 prompt 派生模型适配版，不覆盖标准版。

同时保存渲染清单：模型及版本、尺寸、质量、seed（如可用）、输入图、资产哈希或版本、输出文件和审核状态。Seed 只能提高特定模型内的可复现性，不证明医学正确，也不能跨模型复现。

## 返修分流

- **医学事实层**：修改矢量母版、分层线稿、3D 医学资产或合法真实影像，重新审核后合成。不得让生成模型补骨、韧带、肌腱、病灶、手位或器械。
- **非医学表现层**：可使用上一版作为编辑目标，在明确蒙版内做局部生成；每次只处理一个变更集。
- **文字、标签与气泡**：只在 Illustrator 或等价可编辑矢量工具中修改，不经过图像生成模型。

若医学错误只存在于扁平位图，又没有可编辑母版或合格线稿，停止返修并报告缺少源资产。不得用简单多边形、色块、克隆或涂抹伪装修正。

## 编辑合同与变更集

每次修改前先写：

```markdown
- 页面/对象：
- 修改类型：医学事实层 / 非医学表现层 / 文字层
- 基准版本：
- 本次唯一变更集：
- 允许变化：
- 必须保持不变：
- 修改区/蒙版：
- 保护区/锁定图层：
- 使用的母版、参考图和资产编号：
- 允许工具：
- 验收条件：
- 失败后回退方式：
```

不覆盖原 prompt。保存 `基础 prompt + 变更集 + 新渲染清单`，新建版本化输出。

## 局部修改门禁

同时检查实际成书尺寸、100% 和 200% 放大图，并使用新旧版本叠加或差异图检查：

- 修改区外的人物身份、肢体、医学结构、侧别、箭头、标签、构图和画布尺寸不得变化；
- 修改轮廓必须连续，不得有直线切口、突兀多边形边界或邻区断裂；
- 线宽、描边端点、色阶、纹理、颗粒、光向和透视与原图连续；
- 医学修改须重新检查结构层次、附着、走行、邻接、动作和病灶位置。

修改区外出现未授权差异，或出现可见补丁感，本候选自动失败，不因“整体看起来尚可”放行。
