# 文件与版本管理

沿用现有项目主稿、稳定编号、资产索引与实际目录。新项目可用初始化器的轻量目录，不把某本书的编号、角色、固定页数或文件布局强加给其他项目。

- 每个内容单元仅维护一份当前文字主稿；排字改字回写主稿。页面版本、源文件、导出与审核范围同步。
- 唯一原图、实际提示词/附件/输出、来源凭据及专用程序放正式目录；临时目录只放可再生成内容。工具返回临时文件时先保存并校验再登记。
- 共享资产按来源、版本/哈希引用。上游许可与待审状态随母版继承，不能仅因文件存在推定适用于新用途。
- 冻结的来源、已交付版本与审核证据不改写。旧稿与关闭审核成套归档，必要时记录旧路径、新路径及哈希；不整理其他任务的在制目录。
- 保存共享总控前比较读取时哈希；已改变时重新读取并合并本次修改，避免覆盖并发工作。
- 默认交付已验证文件的链接；固定批次使用普通文件夹，不自动生成 ZIP。只有用户或接收方要求时才压缩。

分别记录制作交付、实际送审及获批准发布；不要凭目录名、版本号或脚本测试通过推定医学批准。交付前核对文件实际存在、大小、路径、版本与检查范围。原始资料和已认可资产保留回退入口。
