# 医学质检、返修与印前

## 错误等级

- **A 级**：可能造成医学误解、错误定位或不安全行为。阻断出版，重画并按风险等级重审。
- **B 级**：简化不当、图文不严谨或容易误认。出版前修改并复核。
- **C 级**：不影响医学含义的美术或文字细节。编辑阶段修正。

审稿意见必须写明页面/图号、对象、错误、正确约束和回归范围，不能只写“需调整”。

## 单页硬检查

- 唯一认知目标清楚；全部医学论断可追溯到证据编号。
- 含医学文案时，医学事实稿与公众表达稿均留存，G6 语义回归已通过；无医学文案时记录不适用并检查未新增医学暗示。
- 术语、数值、否定、条件、概率、时序、风险提示和行动建议未在润色中漂移。
- 图像类型和“示意图/功能模型”声明准确。
- 角色、患侧、服装和受伤侧与母版一致。
- 骨、肢体、手指数目正确；近远端连续。
- 左右、掌背、内外、桡尺侧或胫腓侧正确。
- 结构、层次、附着、走行、运动和生物力学合理。
- 病灶、痛点、切口、穿刺点、箭头和标签定位正确。
- 查体手位、固定端、施力方向、器械和康复阶段正确。
- 影像授权、去标识化、方向、侧别和图注正确。
- 功能模型、拟人画和非诊断示意没有冒充真实结构或影像。
- 图文一致；无自我确诊、危险自测、保证疗效或固定恢复承诺。
- 在实际成书尺寸下文字、细线、箭头和对比度可辨。
- 实际采用的矢量工具中文本仍可编辑，字体、样式、图层和阅读顺序正确；用户指定源格式时另核验该格式。
- 解剖内容已绑定本地参考图及来源登记，参考图的侧别、视角、层次和图中使用方式一致。
- 每张生成图有生成前结构化 prompt 和渲染清单；修改图另有编辑合同和变更集。
- 对白气泡内边距、字号下限、行距、换行、尾巴排除、居中和溢出检查均通过。

## 跨页检查

- 同一角色五官、发型、比例、服装和配饰一致。
- 同一患者的侧别、伤侧、衣着和时间顺序连续。
- 同一结构的颜色、命名、形态和方向不矛盾。
- 相同术语、风险措辞和证据强度在不同页面保持一致。
- 诊断、治疗、固定、康复和重返运动符合时序。
- 前页的比喻在后页没有被当作真实结构。
- 所有修改页完成回归；废弃稿未混入交付目录。

## 返修规则

先按 [revision-and-prompting.md](revision-and-prompting.md) 建立编辑合同：医学修改先改母版/线稿，非医学修改保留基础 prompt 并只新建一个变更集。再生成/绘制新候选，不覆盖旧稿。至少回归检查修改对象、相邻结构、侧别方向、标签正文、人物和上下页。

不允许：整页重生成来修一个局部；用标签解释错误结构；用生成模型或简单多边形/色块补骨、韧带、肌腱或病灶；为版面镜像医学图；修改背景时连同锁定人物和医学层一起重做；修改区外出现未授权差异。

返修后须在实际成书尺寸、100% 和 200% 下检查，并用新旧版本叠加或差异图验证保护区。轮廓断裂、直线切口、多边形补丁、线宽/纹理/光向不连续或保护区变化，候选稿自动失败。

## 变更与批准失效范围

| 变更类型 | 医学批准 | 必须完成的复核 |
|---|---|---|
| 医学结构、侧别、动作、器械、影像、诊疗文字或含医学内容的生成区域变化 | 受影响内容原批准失效 | 更新证据/母版与版本，复核邻近结构、方向、标签、正文和跨页关系，按 H/M 风险重审 |
| 纯装饰、背景或非医学人物表现变化，医学层和医学语义保持不变 | 保护区复核通过后可继承，并记录原签字版本和本次适用范围 | 差异图、角色连续性、遮挡和美术检查；编辑批准按影响重新确认 |
| 纯排字、字距或气泡调整，锁定文案与医学落点不变 | 可继承有效批准 | 文字逐字对照、可读性、箭头落点、溢出和保护区复核；造成医学歧义则转医学变更 |
| 只调整数字导出或印前参数 | 医学含义未变化时可继承 | 检查色彩编码、裁切、清晰度和图层可见性；改变医学含义则重审 |
| 保护区差异无法解释或无法确认医学含义是否变化 | 暂停继承受影响批准 | 定位差异；不能排除医学影响时按医学变更重审 |

继承只表示有依据地延续原批准范围，不得把原审稿人的签字移到未审核的新医学内容上。制作阶段、审核状态和各专业签字记录分开保存。

## 最低放行标准

按风险、制作阶段和交付载体检查适用项。不适用项注明理由；数字作品另执行下文数字交付检查。

- 每条医学结论有可核验证据。
- H/M 图均有空间规格卡。
- 解剖图均有本地参考图包与来源/许可证登记。
- 连续角色与医学结构均来自锁定资产。
- 真实影像合法、去标识化且方向正确，或明确标为非诊断示意。
- A/B 级问题清零；修改页完成回归。
- H 级临床与解剖双审完成。
- 实际尺寸样张完成可读性检查。
- 适用的 G6 文案语义回归和可编辑矢量排字复核通过。
- 素材授权核验通过；印刷作品另通过出版社规格核验和印前预检。

缺少适用检查时不得宣称该阶段已完成。未完成医学审核的内容保留 `草稿` 或 `医学待审`；医学已通过而只差编辑或印前时保留有效医学批准，不降回医学待审。“审校样”“待排字”只记作制作阶段。

## 印前检查

出版社书面规范优先于通用经验。使用 Adobe Illustrator 或等价工具的原生源文件保留可编辑文字和分层母版；用户指定 `.ai` 时单独验收。核查成品尺寸、出血、安全边距、装订口、有效分辨率、色彩空间和 ICC 配置、黑字/细线、字体授权与嵌入/转曲、链接图片、透明度、套印、PDF 标准和跨页处理。

交付时同时提供印刷 PDF、可编辑源文件、链接素材、字体与授权说明、影像/肖像授权、角色和医学母版、证据矩阵、医学审计、签字记录及版本变更表。

## 数字交付检查

纯数字作品不要求出版社出血、装订或印刷 PDF 规格。先确认目标平台、画布像素、预期显示尺寸、阅读顺序、色彩空间和输出格式；初稿可记录暂定值，正式交付前确认。

- 在目标显示尺寸与缩放条件下检查中文缺字、换行、对比度、箭头和细线；检查移动端裁切与压缩。
- 按目标平台核验色彩配置、透明度、像素尺寸、文件格式与文件大小，保留原生可编辑源文件和实际导出文件。
- 医学证据、素材授权、隐私、图文一致及 H/M 所需人工审核仍适用；无医学事实的 L 级内容明确记录医学审核不适用。
- 完成文字与编辑审核，记录数字输出检查结果及项目负责人对当前版本的发布决定。审核状态通常为 `编辑通过`，制作阶段为“数字交付”，印前审核记为不适用。
