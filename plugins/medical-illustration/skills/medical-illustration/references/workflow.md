# 漫画与医学插画流程

沿用项目主稿、编号、资产与视觉基准。单页或局部返修只执行相关部分，不设固定阶段文件、候选数量或审核轮次。

1. **内容与依据：**明确读者问题、医学事实和必要限定，按[参考规则](anatomy-reference-search.md)判断证据充分性。可先探索情节，待核事实标明范围。
2. **视觉设计：**把人物行动、反应和医学解释连起来，决定画面与阅读顺序。按[文字空间](text-space-and-visible-copy.md)规划实际文案，按[文案规则](copy-and-lettering.md)修订表达。仅新复杂页型、画风或角色变化需要针对性试制。
3. **生成与修正：**按[生成与资产](generation-and-assets.md)制作彩色画面或所需中间资产。角色参考锁定身份与比例，姿势、镜头与分镜服务本页内容。
4. **排字：**先用实际文案试排，再建立可编辑文字、气泡及标注。根据交付格式选择 [PPTX](pptx-delivery.md)、[Illustrator](illustrator-runtime.md)或其他可验收工具。改字回写当前脚本。
5. **逐页与跨页复核：**按[质量检查](qa-and-prepress.md)对照实际输出、视觉基准和医学参考，定位并修复缺陷。
6. **登记与交付：**按[文件管理](file-management.md)固定批次与保存依据，审核状态按[共用规则](../SKILL.md#共用医学与进度规则)记录。

返修直接进入对应步骤，按质量规则确定修改对象、保护区域和复核范围。新旧资产均按本次视角、动作和用途核对适用性。
