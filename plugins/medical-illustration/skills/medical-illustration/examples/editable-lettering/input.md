# 页面任务与版面规格 V1.0

- 目标：展示“整理想表达的信息”的一页无医学论断版面，并演示无字底版到可编辑排字。
- 载体：数字 SVG，800 × 1000；PDF 为同尺寸审阅副本，不作印刷承诺。
- 风险：L。无人物、解剖、疾病、诊疗、器械、医学影像或动作示教。
- 本次范围：新建版面、独立文字层、PNG 预览及 PDF 导出。与 generic-visit-preparation 的人物草图属于不同示例。
- 文字基线：就诊前／整理想说的话；把想表达的信息，写在自己的便签上。；我想先写下来，／再慢慢说明白。；我想说的事；我想问的问题；留给自己的备注。
- 表现：浅米白背景、墨绿标题、暖黄提示卡、三张线性便签卡；无身份数据和医疗机构标识。
- 图层：background、artwork、lettering、review。artwork 中对象保持一致；文字通过 SVG text 对象添加。
- 医学证据、本地解剖参考、医学母版、角色系统：均不适用，原因是本页无相应内容。
- 工具：确定性 SVG 文档构建；Chromium 导出 PDF/PNG。没有使用生成式图像模型。
- 约束：不将文字转曲，不新增医学暗示，底版与排字版的 artwork 层一致。
- 审核状态：草稿。工具检查不代表人工编辑批准。
