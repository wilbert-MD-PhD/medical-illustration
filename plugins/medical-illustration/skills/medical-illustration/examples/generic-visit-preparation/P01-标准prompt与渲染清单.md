# 标准 prompt V0.1

- 页面/图号：P01。
- 用途与唯一认知目标：安装验收草图；显示虚构成年人在就诊前整理自己想表达的信息。
- 画布与实际阅读尺寸：竖版单页，草图 1200 × 1600 px；未取得出版规格。
- 场景与主体：家庭书桌，一名无特定身份的虚构成年人，空白便签和日历。
- 视角、镜头与构图：平视中景，人物在左，右上预留空白对话气泡位置，阅读方向从左到右。
- 人物、动作与角色资产：一次性虚构成年人，正常坐姿，一手扶纸，一手持笔；无连续角色资产。
- 医学空间规格：不适用；不展示解剖、病灶、查体、器械、康复动作或医学影像。
- 解剖参考图与医学母版：不适用。
- 风格、色彩、光线与媒介：简洁二维科普漫画，柔和中性配色，白天室内光，无品牌标志。
- 锁定项：成年人、桌面、笔、空白便签、日历、空白气泡；便签和气泡内均无文字。
- 允许变化项：虚构人物的非识别性外观、普通家居装饰和低风险配色。
- 禁止项：真人肖像、姓名、电话、病历号、医院标志、疾病名、症状文字、诊断、药物、医疗器械、自测动作、解剖图、医学影像、水印和生成式文字。
- 分层与无文底图要求：背景、人物、桌面物件和空白气泡尽可能分层；交付无文底图。
