# 变更记录

## 1.0.0-rc.5

- 新增首次环境检查，分别确认安装、图像生成、中文字体、可编辑排字和 PDF 导出。
- 补充按需安装免费依赖的路径，避免强制安装可选技能和商业软件。
- 分享说明包含安装、依赖验收和首次任务；Release 页说明各下载文件的用途。


## 1.0.0-rc.4 · 2026-09-07

- 提供带版本与准确目录的两行安装提示和可转发安装说明。
- 明确纯文字返修的排字规范入口，医学批准按受影响范围失效。
- 源资产缺失时，允许依据合格参考重建待审医学线稿；保留保护区与对应审核要求。
- 发布检查纳入子目录同名校验文件，新增完整性回归测试。

## 1.0.0-rc.3 · 2026-09-07

- 统一 Marketplace 仓库、插件目录与独立 Skill ZIP 的安装说明，提供准确子目录。
- 改为先核验与复用合格本地参考，缺项时再联网补齐；保留证据核验与人工医学审核。
- 新建低风险可编辑排字示例，包含输入规格、无字 SVG、排字 SVG、PNG 和 PDF 审阅稿及来源记录。
- 从完整版本标签构建 Unicode ZIP，验证默认解压、清单、链接和源码一致性。
- 为含中文模板的 Python 源码明确 UTF-8 编码并展开长字符串；错误路径测试验证业务错误，拒绝把 SyntaxError 算作成功拦截。
- 仓库加入 Windows/macOS/Linux 包验证、发布边界回归测试与标签发布工作流。

本地已执行初始化器和包校验，并检查示例 PNG/PDF 实际渲染。跨平台运行结果见仓库 Actions；独立新会话行为、完整医学图像生成及原生 .ai 工作流仍需各自验证。工具结果不代表人工医学批准。

已知旧版问题：rc.2 的 Git 标签仅包含 README，上传 ZIP 的中文文件名未置 UTF-8 标记。本版使用新标签和新附件，不移动旧标签。

## 1.0.0-rc.2 · 2026-09-06

- 保留标准输出和错误输出的原编码，将不可表示字符转义，避免模板已生成却因中文日志报错；帮助及参数错误输出也受此处理保护。
- 文件内容继续显式使用 UTF-8；测试子进程与测试程序采用明确一致的编码。
- 增加 CP1252、ASCII、GBK 模拟输出的初始化、重复执行、错误与帮助测试；共 12 项测试。
- 主文件统一使用 python3，并说明 Windows 的 py -3 替代命令。

本轮验证仍在 macOS / Python 3.13.1 上完成，输出流编码模拟不代表 Windows/Linux 实机验收。

验证使用 Python 3.13.1 在 macOS 上执行。发布候选不代表已完成 Windows/Linux 安装、新会话 agent 行为验收、真实图像生成或矢量排字实测，也不代表任何医学作品通过审核。
